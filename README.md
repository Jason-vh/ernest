An Amsterdam rental-hunting map.

2025 — 2026.

He found the house.

---

The full app lives in git history. What ships now is `index.html` (the memorial) and `server.ts` (a tiny Bun server that serves it).

```sh
bun install
bun run start    # production, listens on $PORT (default 3000)
bun run dev      # hot reload
```
